# v1.1.0 brand assets (archived)

Superseded in v1.2.0 by assets traced from the approved brand board
(`docs/brand/culina-brand-board.png`). The v1.1.0 mark was a specification
reconstruction (golden/orange C arc + chef hat + fork + spoon + cocktail +
leaf + flame drawn from the written spec), not the board artwork; the v1.1.0
mark-region assumption pointed at photographic texture rather than the
emblem (see `docs/brand/BOARD-FORENSICS.md`).

These files are retained for provenance only — nothing in the app, tests or
docs may reference them.
