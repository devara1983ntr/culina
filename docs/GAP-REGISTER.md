### Explicitly checked and NOT gaps (evidence)

- **No fake data / placeholders / dead paths**: repo-wide marker sweep (TODO/FIXME/HACK/XXX/coming soon/mock/dummy/fake/temporary) → 38 matches, all legitimate (HTML `placeholder` attributes, honest-copy comments like "never faked", the real API name "BaconMockup"). No `html:` prop call sites → the single `innerHTML` sink in `dom.js` is unused by application code.
- **Secrets**: key/token/password sweep → clean; the proxied provider is keyless by design (`server.js` header comment).
- **Storage corruption**: `read()` catches JSON parse failures and returns fallback; `write()` degrades to memory on quota errors; v0→v1 migration preserves unknown data (unit-tested in `tests/storage.test.js`, `tests/expansion.test.js`).
- **Request lifecycle**: 9 s timeout, in-flight dedupe, GET-only retry with backoff, abort composable with route cancellation (unit-tested; E2E stuck-skeleton audit).
- **Voice search**: real `SpeechRecognition` integration, feature-gated (button absent where API is unavailable), full lifecycle handlers, `aria-pressed` state.
- **Share**: `navigator.share` → clipboard fallback → error toast.
- **External links**: 10 sites, all `rel="noopener noreferrer"`; `safeUrl()` enforces http(s) protocol.
- **PWA assets**: manifest with 192/512/maskable icons + shortcuts; apple-touch-icon; dual theme-color; branded offline.html.
- **Dark-theme contrast**: the initial E2E contrast "failures" (body/dark 2.70:1 etc.) were measurement artifacts — the checker read the body background mid-transition and did not composite translucent badge tints. After fixing the checker (transition wait + alpha compositing), all spot-checks pass ≥ 4.5:1 in both themes on both engines.
- **Voice search, share, settings export/import**: all real implementations with graceful fallbacks (feature-detected SpeechRecognition; navigator.share → clipboard → toast; validated JSON import with `app` marker check).
